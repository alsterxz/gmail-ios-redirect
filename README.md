# Gmail iOS Redirect

Redirector estático para abrir una conversación concreta en Gmail para iPhone desde enlaces HTTPS publicados por el Radar de Compromisos.

## Uso

```text
https://alsterxz.github.io/gmail-ios-redirect/?id=<GMAIL_THREAD_ID>
```

No usa cookies, analítica, almacenamiento ni backend. Valida el identificador y abre `googlegmail:///cv=<id>/accountId=0`.
